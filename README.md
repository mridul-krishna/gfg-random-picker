# GFG Random Question Picker

A Chrome extension that randomly selects a problem from the currently
loaded GeeksforGeeks practice problems.

## Current Features

- Detects GFG problem rows
- Removes duplicate problem entries
- Counts available problems
- Randomly selects a problem
- Opens the selected problem using GFG's own interface

## Current Limitation

The extension can only select from problems currently loaded on the page.

If GFG has a "Load More" button, additional problems must currently be
loaded manually.

## Installation

1. Clone/download this repository.
2. Open `chrome://extensions`.
3. Enable Developer Mode.
4. Click "Load unpacked".
5. Select the project folder.
